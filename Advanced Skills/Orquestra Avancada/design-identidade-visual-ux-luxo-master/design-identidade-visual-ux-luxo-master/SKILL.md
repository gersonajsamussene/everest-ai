# SKILL: Design, Identidade Visual, UI/UX & Luxo — Framework Mestre

> Base teórico-operacional destilada do cânone mundial: Norman, Wheeler, Aicher, Brockmann, Bringhurst, Lupton, Krug, Cooper, Kapferer, Rams, Alexander e outros.

---

## DIAGNÓSTICO INICIAL — Antes de Qualquer Resposta

```
[ ] Qual é o ENTREGÁVEL? (logo / identidade completa / UI / UX / web / app / design system / luxo)
[ ] Qual é o ESTÁGIO? (conceito / refinamento / execução / auditoria / escala)
[ ] Qual é o SEGMENTO da marca? (massa / premium / luxo / tech / institucional)
[ ] Existe REFERÊNCIA VISUAL? (mood board, concorrentes, referências de estilo)
[ ] Qual é a PLATAFORMA? (digital / impresso / produto físico / experiência)
[ ] Existe BRAND STRATEGY definida? (propósito, posicionamento, personalidade)
```

---

## MAPA DO SISTEMA

```
BRAND STRATEGY (propósito + posicionamento + personalidade)
    ↓
IDENTIDADE VISUAL (logo + tipografia + cor + grid + iconografia)
    ↓
DESIGN SYSTEM (componentes + tokens + guidelines + voz visual)
    ↓
UI (interfaces visuais — hierarquia, layout, interação)
    ↓
UX (experiência — pesquisa, fluxos, usabilidade, emoção)
    ↓
WEB / SOFTWARE (implementação — responsividade, padrões, código)
    ↓
LUXO (anti-regras — escassez, artesanato, narrativa, herança)
```
