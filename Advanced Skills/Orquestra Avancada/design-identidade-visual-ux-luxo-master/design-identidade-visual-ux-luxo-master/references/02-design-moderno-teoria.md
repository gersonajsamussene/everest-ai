## OS 10 PRINCÍPIOS DE BOM DESIGN — DIETER RAMS

Dieter Rams (Braun, 1960s) criou os princípios que inspiraram Jony Ive e o design da Apple:

| # | Princípio | O que significa |
|---|-----------|----------------|
| 1 | **Inovador** | Possibilidades de inovação não se esgotam |
| 2 | **Útil** | Um produto serve para ser usado — satisfazer função é prioritário |
| 3 | **Estético** | A qualidade estética é parte integral da utilidade |
| 4 | **Compreensível** | Clarifica a estrutura do produto — autoexplicativo |
| 5 | **Discreto** | Não decorativo, não um objeto de arte — neutro como ferramenta |
| 6 | **Honesto** | Não faz o produto parecer mais inovador, poderoso ou valioso do que é |
| 7 | **Duradouro** | Evita estar na moda — nunca parece antiquado |
| 8 | **Detalhado** | Nada é arbitrário ou casual — cuidado e precisão no processo |
| 9 | **Ecológico** | Conserva recursos, minimiza poluição visual e física |
| 10 | **Mínimo** | Less but better — concentração nos essenciais |

> *"Indifference towards people and the reality in which they live is actually the one and only cardinal sin in design."* — Dieter Rams

## GRID SYSTEMS (Josef Müller-Brockmann)

O grid não é uma prisão — é uma linguagem de ordem que libera a criatividade.

### Anatomia do Grid

```
MARGEM          → Espaço entre o conteúdo e a borda
COLUNA          → Unidade vertical de organização
SARJETA (Gutter) → Espaço entre colunas
LINHA DE BASE   → Grade horizontal de alinhamento tipográfico
MÓDULO          → Interseção de coluna e linha de base
```

### Grids mais usados

| Grid | Uso típico |
|------|-----------|
| **Manuscrito** (1 coluna) | Livros, artigos longos |
| **Colunar** (2–5 colunas) | Revistas, jornais, web editorial |
| **Modular** | Tabelas, interfaces complexas, catálogos |
| **Hierárquico** | Layouts únicos, landing pages, posters |

### Proporções Clássicas
- **Proporção áurea (φ = 1.618):** Base de composições visuais harmônicas
- **Regra dos terços:** Grid 3×3 — pontos de interesse nos cruzamentos
- **Seção de ouro:** Aplicada a proporções de logo, página e composição

## TIPOGRAFIA — FUNDAMENTOS (Bringhurst + Lupton)

### Anatomia do Tipo
```
Ascendente    → Parte que sobe além da altura-x (b, d, h, k)
Descendente   → Parte que desce abaixo da linha de base (p, q, g, y)
Altura-x      → Altura das letras minúsculas (x como referência)
Cap Height    → Altura das letras maiúsculas
Tracking      → Espaçamento geral entre letras (espaço de letra)
Kerning       → Ajuste óptico entre pares específicos de letras
Leading       → Espaçamento entre linhas (entrelinha)
```

### Classificação de Tipos

| Categoria | Características | Exemplos | Uso |
|-----------|----------------|---------|-----|
| **Serif** | Hastes com serifa | Garamond, Times, Georgia | Corpo de texto longo, autoridade |
| **Sans-serif** | Sem serifa, linhas limpas | Helvetica, Futura, Inter | Interface, modernidade |
| **Slab Serif** | Serifa grossa e retangular | Rockwell, Courier | Personalidade forte, destaque |
| **Script** | Cursiva, escrita à mão | Pacifico, Brush Script | Luxo, elegância, informalidade |
| **Display** | Para título, não corpo | Bebas Neue, Playfair Display | Headlines de impacto |
| **Monospace** | Largura igual para cada letra | Courier, Monaco | Código, técnico, retrô |

### Regras de Combinação Tipográfica
1. **Contraste antes de harmonia** — combinar tipos muito similares cria tensão incômoda
2. **Máximo 2–3 tipos** por sistema de identidade
3. **Misturar categorias** — serif com sans-serif funciona melhor que duas serifs
4. **Hierarquia clara** — tamanho, peso e cor definem a estrutura de leitura
5. **Testar no contexto real** — tipo que funciona no specimen pode falhar no uso

## TEORIA DA COR (Josef Albers + James Gurney)

### Modelos de Cor para Design

| Modelo | Uso | Componentes |
|--------|-----|-------------|
| **RGB** | Telas digitais | Red, Green, Blue (0–255) |
| **CMYK** | Impressão | Cyan, Magenta, Yellow, Key (Black) |
| **HSB/HSL** | Design digital intuitivo | Hue, Saturation, Brightness/Lightness |
| **Pantone (PMS)** | Impressão precisa, cor de marca | Códigos padronizados universais |

### Psicologia da Cor Aplicada a Marca

| Cor | Associações positivas | Riscos |
|-----|----------------------|--------|
| **Vermelho** | Energia, paixão, urgência | Agressividade, perigo |
| **Azul** | Confiança, profissionalismo, calma | Frieza, distância |
| **Verde** | Natureza, saúde, crescimento | Inexperiência (verde-limão) |
| **Amarelo** | Otimismo, criatividade, atenção | Ansiedade, excesso |
| **Laranja** | Amizade, vitalidade, acessível | Falta de sofisticação |
| **Roxo** | Luxo, espiritualidade, criatividade | Artificialidade |
| **Preto** | Luxo, autoridade, elegância | Luto, negatividade |
| **Branco** | Pureza, simplicidade, espaço | Vazio, frieza |
| **Dourado** | Riqueza, prestígio, exclusividade | Ostentação |

### A Descoberta de Albers: Cores Mudam Dependendo do Contexto
> Nunca existe cor absoluta. A mesma cor parece diferente dependendo das cores ao redor.

**Implicação:** Sempre testar paletas no contexto de uso real — não em swatches isolados.

## COMPOSIÇÃO VISUAL — PRINCÍPIOS FUNDAMENTAIS

### Os 125 Princípios (Universal Principles of Design)

Os mais críticos para identidade e design visual:

| Princípio | Aplicação |
|-----------|----------|
| **Figura-Fundo** | Relação entre elemento e espaço negativo (logo FedEx, seta) |
| **Gestalt (Proximidade)** | Elementos próximos são percebidos como grupo |
| **Gestalt (Similaridade)** | Elementos similares são percebidos como relacionados |
| **Gestalt (Continuidade)** | Olho segue linhas e curvas naturalmente |
| **Gestalt (Fechamento)** | Mente completa formas incompletas (logos negativos) |
| **Hierarquia Visual** | Tamanho, cor e posição guiam a leitura |
| **Contraste** | Diferença cria interesse e hierarquia |
| **Alinhamento** | Cria ordem visual e profissionalismo |
| **Repetição** | Consistência cria identidade reconhecível |
| **Espaço Negativo** | O que não está lá define o que está |
