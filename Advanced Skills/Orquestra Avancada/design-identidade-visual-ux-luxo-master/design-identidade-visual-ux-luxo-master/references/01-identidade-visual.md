# 01 — Identidade Visual & Design de Marca

---

## PROCESSO DE IDENTIDADE VISUAL (Alina Wheeler — Designing Brand Identity)

O processo padrão global em 5 fases:

```
FASE 1: PESQUISA & ESTRATÉGIA
  → Audit da marca atual (se existir)
  → Pesquisa de mercado, concorrentes, audiência
  → Articulação do posicionamento e personalidade da marca
  → Brief criativo validado com stakeholders

FASE 2: EXPLORAÇÃO DE CONCEITO
  → Geração de conceitos visuais (sketching)
  → Exploração de direções (ao menos 3 caminhos distintos)
  → Não partir para digital antes de esgotar o analógico

FASE 3: REFINAMENTO
  → Selecionar 1–2 direções para desenvolver
  → Refinamento do símbolo, tipografia, cor
  → Testar em contextos reais (escala, fundo escuro/claro, movimento)

FASE 4: SISTEMA
  → Construir o sistema completo (logomark + logotype + versões)
  → Definir paleta cromática (primária + secundária + neutros)
  → Selecionar tipografia (primária + secundária + sistema)
  → Criar grid e princípios de layout

FASE 5: IMPLEMENTAÇÃO & GUIDELINES
  → Brand guidelines / Manual de identidade
  → Arquivos em todos os formatos necessários
  → Templates para aplicações primárias
```

## ANATOMIA DO LOGO

### Tipos de Logo

| Tipo | Descrição | Exemplos |
|------|-----------|---------|
| **Wordmark** | Apenas tipografia | Google, Coca-Cola, FedEx |
| **Lettermark** | Iniciais | IBM, HP, CNN |
| **Brandmark / Símbolo** | Ícone sem texto | Apple, Nike Swoosh, Twitter |
| **Combination Mark** | Símbolo + texto | Amazon, Adidas, Lacoste |
| **Emblem** | Texto dentro do símbolo | Starbucks, Harley Davidson, NFL |
| **Dynamic / Adaptável** | Muda por contexto | MTV, Google Doodle |

### Critérios de um Logo Eficaz (David Airey)
```
[ ] Simples — funciona em qualquer tamanho?
[ ] Memorável — permanece na mente após 1 exposição?
[ ] Atemporal — evita tendências que envelhecem?
[ ] Versátil — funciona em P&B, cores inversas, bordado, gravura?
[ ] Apropriado — comunica o setor e a personalidade certa?
[ ] Único — diferente de todos os concorrentes diretos?
```

## SISTEMAS DE IDENTIDADE — O QUE VAI ALÉM DO LOGO

Um sistema de identidade completo inclui:

```
NÚCLEO
  → Logo (todas as versões: horizontal, vertical, símbolo)
  → Paleta de cores (primária, secundária, neutros, uso digital vs. impresso)
  → Tipografia (primária, secundária, fallback para web)
  → Voz visual (estilo fotográfico, ilustrativo, iconográfico)

EXTENSÕES
  → Grid e princípios de layout
  → Iconografia
  → Motion e animação (marca em movimento)
  → Tom de voz (verbal identity integrada ao visual)

APLICAÇÕES
  → Papelaria (cartão, papel carta, envelope)
  → Digital (favicon, social media, e-mail)
  → Produto / embalagem
  → Ambiental (sinalização, espaço físico)
  → Branded content
```

## LOGO MODERNISM — PRINCÍPIOS DO MODERNISMO VISUAL

Do arquivo histórico de Jens Müller (3.500 logos, 1940–1980):

**Princípios do logo modernista clássico:**
1. **Redução máxima** — eliminar tudo que não é essencial
2. **Geometria pura** — círculo, quadrado, triângulo como bases
3. **Equilíbrio visual** — não matemático — óptico
4. **Unicidade** — um conceito, uma forma, uma ideia
5. **Funcionalidade** — serve antes de decorar

**Designers que definiram a linguagem:**
- **Paul Rand** — IBM, ABC, UPS, NeXT (conceito + função + simplicidade)
- **Saul Bass** — AT&T, United Airlines, Girl Scouts (narrativa em forma)
- **Otl Aicher** — Olimpíadas Munique 1972, Lufthansa (sistema visual total)
- **Massimo Vignelli** — NYC Subway, American Airlines, Knoll (grid como religião)

## BRAND GUIDELINES — ESTRUTURA DO MANUAL

```
1. BRAND FOUNDATION
   → Missão, visão, valores
   → Posicionamento e propósito
   → Personalidade e tom de voz

2. LOGO
   → Logo principal e versões
   → Área de proteção (clear space)
   → Tamanho mínimo
   → Usos incorretos (o que NUNCA fazer)

3. CORES
   → Paleta completa com códigos (HEX / RGB / CMYK / Pantone)
   → Hierarquia de uso (primária, secundária, accent)
   → Proporções de uso

4. TIPOGRAFIA
   → Fontes principais com download/licença
   → Hierarquia (H1, H2, H3, body, caption)
   → Espaçamento e alinhamento
   → Fontes alternativas (fallback web/sistema)

5. FOTOGRAFIA & IMAGEM
   → Estilo e mood
   → O que usar e o que evitar
   → Tratamentos e filtros

6. LAYOUTS & GRID
   → Princípios de composição
   → Margens, colunas, proporções

7. APLICAÇÕES
   → Templates de cada aplicação primária
```

## CHECKLIST — AUDITORIA DE IDENTIDADE VISUAL

```
[ ] O logo funciona em P&B sem perder reconhecimento?
[ ] O logo é legível em 16px (favicon)?
[ ] A paleta tem contraste suficiente para acessibilidade (WCAG AA)?
[ ] A tipografia tem licença para todos os usos planejados?
[ ] Existe versão para fundo escuro e fundo claro?
[ ] O sistema é consistente em todas as aplicações?
[ ] As guidelines são claras o suficiente para um terceiro aplicar?
[ ] A identidade se diferencia visualmente de todos os concorrentes diretos?
```
