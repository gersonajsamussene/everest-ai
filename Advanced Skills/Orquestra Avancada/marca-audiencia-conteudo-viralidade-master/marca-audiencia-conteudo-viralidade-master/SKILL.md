# SKILL: Marca, Audiência, Conteúdo & Viralidade — Framework Mestre

> Base teórico-operacional destilada do cânone mundial: Vaynerchuk, Aaker, Neumeier, Sinek, Godin, Berger, Gladwell, Campbell, Miller, Pulizzi, Brunson e outros.

---

## DIAGNÓSTICO INICIAL — Antes de Qualquer Resposta

```
[ ] Qual é o OBJETIVO? (crescer audiência / viralizar / construir autoridade / vender / posicionar marca)
[ ] Qual é o AVATAR? (quem deve me encontrar, seguir, comprar)
[ ] Qual é a PLATAFORMA PRINCIPAL? (Instagram / Facebook / YouTube / LinkedIn / TikTok / E-mail)
[ ] Existe CONTEÚDO existente? (zero / irregular / consistente)
[ ] É marca PESSOAL ou marca CORPORATIVA?
[ ] Qual é o NÍVEL de reconhecimento atual? (desconhecido / nicho / autoridade / escala)
```

---

## MAPA DO SISTEMA

```
IDENTIDADE DE MARCA (quem você é + por que existe)
    ↓
POSICIONAMENTO (onde você ocupa na mente da audiência)
    ↓
AUDIÊNCIA IDEAL (dream follower / avatar)
    ↓
CONTEÚDO (formato + frequência + plataforma + voz)
    ↓
STORYTELLING (narrativa que conecta e converte)
    ↓
VIRALIDADE (mecanismos de propagação)
    ↓
CONVERSÃO (audiência → lead → cliente → superfã)
```
