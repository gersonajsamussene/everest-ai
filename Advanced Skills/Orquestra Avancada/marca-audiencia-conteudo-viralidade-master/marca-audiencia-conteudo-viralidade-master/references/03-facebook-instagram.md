# 03 — Facebook & Instagram — Estratégia & Crescimento

---

## LÓGICA DO ALGORITMO — O QUE REALMENTE IMPORTA

Ambas as plataformas (Meta) distribuem conteúdo baseadas em:

```
1. INTERESSE DO USUÁRIO
   → Histórico de interações com tipo de conteúdo similar
   → Quanto tempo passa vendo seu conteúdo (watch time / dwell time)

2. RELACIONAMENTO
   → Frequência de interação entre contas
   → DMs, comentários, tags, salvamentos

3. RELEVÂNCIA DO CONTEÚDO
   → Sinais de engajamento: saves > shares > comments > likes
   → Rapidez do engajamento após publicação ("spike inicial")

4. TIPO DE CONTEÚDO
   → Cada plataforma favorece formatos nativos
   → Instagram: Reels > Carrossel > Foto > Stories
   → Facebook: Reels > Vídeo > Link posts
```

**Regra geral:** O algoritmo distribui mais para quem gera mais tempo de tela. Não tente "hackear" — crie conteúdo que as pessoas queiram consumir até o fim.

## INSTAGRAM — ESTRATÉGIA POR OBJETIVO

### Crescimento de Seguidores
```
→ Reels com hook forte nos primeiros 2s
→ Hashtags de nicho (não as maiores — as mais relevantes)
→ Colaborações (collab posts, lives conjuntas)
→ Consistência: 4–7 Reels/semana para fase de crescimento
→ Call-to-action para seguir ao final de cada Reel de valor
```

### Engajamento
```
→ Carrosséis educativos (save rate alto)
→ Perguntas nos Stories (caixa de perguntas, enquetes)
→ "Salva isso para mais tarde" como CTA explícito
→ Responder TODOS os comentários nas primeiras 2h
```

### Conversão (Leads e Vendas)
```
→ Link na bio (use Linktree ou página própria)
→ Stories com swipe-up / link sticker
→ DM automation (ManyChat) para entrega de lead magnets
→ "Me manda uma DM com a palavra X" como CTA
```

## FRAMEWORK JAB, JAB, JAB, RIGHT HOOK POR PLATAFORMA

**Gary Vaynerchuk — O erro fatal:**
Usar Instagram/Facebook apenas para pitch e promoção sem dar valor antes.

```
JABS (dar valor):
  → Conteúdo educativo (ensinar algo útil)
  → Conteúdo de entretenimento (fazer rir, emocionar)
  → Conteúdo inspiracional (história, vulnerabilidade)
  → Conteúdo interativo (pergunta, enquete, quiz)

RIGHT HOOKS (pedir algo):
  → Oferta, desconto, lançamento
  → Convite para webinar, evento
  → CTA direto para compra
```

**Proporção saudável:** 4:1 mínimo (4 jabs para cada right hook)

## CONTEÚDO NATIVO POR FORMATO — INSTAGRAM

| Formato | Melhor uso | Métricas chave | Dica crítica |
|---------|-----------|---------------|-------------|
| **Reels** | Crescimento / descoberta | Views, plays, shares | Hook nos primeiros 2s — visual ou texto |
| **Carrossel** | Educação / autoridade | Saves, swipes | Primeira imagem = headline de post |
| **Stories** | Relacionamento / proximidade | Respostas, cliques | Informal, bastidores, interativo |
| **Feed Foto** | Estética / branding | Likes, comentários | Faz parte da identidade visual do perfil |
| **Lives** | Conversão / perguntas | Pico de espectadores | Anunciar com antecedência |

## FACEBOOK — O QUE AINDA FUNCIONA

**Grupos:**
- Comunidades de alto engajamento (algoritmo favorece grupos)
- Construção de tribo ao redor de interesse comum
- Monetização via membership ou produto para o grupo

**Facebook Ads (para além do orgânico):**
- Custom Audiences (e-mail list → lookalike)
- Retargeting (visitantes do site, engajamento no perfil)
- Lead Ads (formulário dentro do Facebook — friction zero)
- Video Views → Retargeting para quem assistiu 75%+

**O que morreu no Facebook:**
- Página orgânica sem ads → alcance próximo de zero
- Posts de link com preview → penalizados pelo algoritmo
- Conteúdo de baixa qualidade compartilhado em massa

## ONE MILLION FOLLOWERS — FRAMEWORK BRENDAN KANE

**Princípio central:** Conteúdo é hipótese. Teste em escala para descobrir o que ressoa.

**Sistema de testes:**
1. Criar 20–30 variações de conteúdo com ângulos diferentes
2. Boostar cada um com pequeno budget ($1–5) para 10.000–50.000 pessoas
3. Identificar os 3–5 que têm CTR e engajamento acima da média
4. Escalar apenas o que foi validado
5. Repetir o ciclo com novas variações a partir dos aprendizados

**O que testar:**
- Hook (primeiros 3 segundos / primeira linha)
- Formato (vídeo vs. imagem vs. carrossel)
- Tom (educativo vs. emocional vs. controverso)
- CTA (qual ação específica pedir)

## MÉTRICAS QUE IMPORTAM (vs. Métricas de Vaidade)

| Métrica de Vaidade | Métrica Real |
|-------------------|-------------|
| Total de seguidores | Taxa de crescimento semanal |
| Likes totais | Taxa de engajamento (eng/reach) |
| Impressões | Alcance de não-seguidores |
| Views de Reels | Watch-through rate (% que assiste até o fim) |
| Comentários totais | Qualidade dos comentários (conversas reais) |
| Stories views | Respostas / replies de Stories |

**Benchmarks saudáveis:**
- Taxa de engajamento Instagram: 3–6% (micro), 1–3% (macro)
- Watch-through Reels: >40% bom, >60% excelente
- Save rate carrossel: >2% excelente

## ESTRATÉGIA DE CRESCIMENTO — 90 DIAS

```
DIAS 1–30: FUNDAÇÃO
  → Definir nicho e avatar específico
  → Otimizar bio (quem você ajuda + o que fazem depois de seguir)
  → Produzir 20 posts de pillar content (os mais importantes da conta)
  → Publicar 5x/semana

DIAS 31–60: TRAÇÃO
  → Analisar os 3 posts com melhor desempenho — fazer mais igual
  → Colaborações com 3–5 contas do mesmo nicho
  → Engajar ativamente em contas do nicho (comentários reais, não genéricos)
  → Testar formatos: qual tem melhor reach?

DIAS 61–90: ESCALA
  → Dobrar frequência do formato vencedor
  → Primeira CTA clara para lista de e-mail ou lead magnet
  → Iniciar Stories diários para aquecer audiência existente
  → Avaliar: qual conteúdo trouxe mais seguidores qualificados?
```
