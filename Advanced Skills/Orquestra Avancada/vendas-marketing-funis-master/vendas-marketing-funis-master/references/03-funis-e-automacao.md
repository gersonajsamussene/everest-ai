## VALUE LADDER (Escada de Valor — Russell Brunson)

```
FREE    → Lead Magnet / Conteúdo gratuito
LOW     → Produto de entrada (R$27–R$97)    — reduz barreira
CORE    → Produto principal (R$297–R$997)
HIGH    → Mentoria / Programa Premium (R$2k–R$20k+)
BACKEND → Continuidade / Mastermind / Licenciamento
```

> A maioria dos negócios falha porque tenta vender o produto CORE para tráfego frio. A value ladder aquece o lead em etapas.

## SEQUÊNCIA DE E-MAIL AUTOMATIZADA (Ryan Deiss — Invisible Selling Machine)

```
Fase 1 — INDOCTRINATION (dias 1–7)
  → Quem sou, minha história, minha filosofia
  → Por que sou diferente, o que o lead pode esperar

Fase 2 — ENGAGEMENT (dias 8–21)
  → Conteúdo de valor, histórias, provas
  → Antecipação e quebra de objeções

Fase 3 — ASCENSION (ongoing)
  → Oferta do próximo nível da value ladder
  → Upsell, cross-sell, programa premium

Fase 4 — SEGMENTATION
  → Separar quem comprou / não comprou / abriu / clicou
  → Criar trilhas específicas por comportamento

Fase 5 — RE-ENGAGEMENT
  → Reativar leads frios com nova narrativa ou nova oferta
  → "Você ainda está interessado em [resultado]?"
```

## SEQUÊNCIA DE CRENÇA (Expert Secrets — Brunson)

Para vender qualquer coisa, o avatar precisa acreditar em 3 coisas:
1. **O veículo** é o certo (o método/produto funciona)
2. **Ele mesmo** é capaz de executar
3. **O tempo/situação** atual é propício

Cada objeção de compra é uma dessas 3 crenças quebrada. O funil deve reconstruir cada uma sistematicamente.

## ESTRUTURA DE WEBINAR PERFEITO

```
[0–5min]    Hook + Promessa do que vai aprender
[5–15min]   História de origem (quem sou, como descobri)
[15–45min]  Conteúdo de valor (3 segredos / pilares)
             → Cada "segredo" quebra uma crença negativa
[45–55min]  Transição para a oferta (a lógica da oferta)
[55–70min]  Revelar a oferta + value stack
[70–80min]  Perguntas e respostas + CTA final
```

## UPSELL / DOWNSELL / OTO

- **OTO (One Time Offer):** Imediatamente após opt-in ou compra. Alta urgência, desconto real.
- **Upsell:** Versão mais completa / premium / feita para você
- **Downsell:** Versão reduzida para quem recusou o upsell (preservar o cliente)
- **Order Bump:** Checkbox na página de checkout (pequeno complemento, alta conversão)

> Regra: Nunca deixe o cliente comprar e sair sem pelo menos uma oferta adicional.
