# SKILL: Vendas, Marketing, Funis & Publicidade — Framework Mestre

> Base teórico-operacional destilada do cânone mundial: Cialdini, Hormozi, Brunson, Ogilvy, Schwartz, Halbert, Kahneman, Rackham, Godin e outros.

---

## DIAGNÓSTICO INICIAL — Antes de Qualquer Resposta

Antes de executar qualquer tarefa, identifique:

```
[ ] Qual é o PRODUTO ou SERVIÇO?
[ ] Qual é o AVATAR (cliente ideal)?
[ ] Qual é o NÍVEL DE CONSCIÊNCIA do mercado? → ver references/01-consciencia-e-psicologia.md
[ ] Qual é o OBJETIVO IMEDIATO? (gerar lead / vender / engajar / viralizar)
[ ] Qual é o CANAL/PLATAFORMA? (Instagram, YouTube, e-mail, funil, etc.)
[ ] Existe OFERTA definida? → ver references/02-ofertas-e-vendas.md
```

A resposta muda radicalmente conforme essas variáveis. Não pule este passo.

---

## MAPA DO SISTEMA

```
TRÁFEGO (orgânico + pago)
    ↓
CONSCIÊNCIA (níveis 1–5 de Schwartz)
    ↓
OFERTA IRRESISTÍVEL (Hormozi: valor percebido >> preço)
    ↓
FUNIL (Brunson: value ladder + sequência de crença)
    ↓
COPY (Hopkins → Ogilvy → Halbert → Schwartz)
    ↓
AUTOMAÇÃO (Deiss: Indoctrination → Engagement → Ascension)
    ↓
RETENÇÃO / VIRALIZAÇÃO (Berger: STEPPS)
```
