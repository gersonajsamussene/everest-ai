# SKILL: Negócios, Economia, Finanças & Comportamento — Framework Mestre

> Base teórico-operacional destilada do cânone mundial: Drucker, Porter, Christensen, Kahneman, Thaler, Graham, Damodaran, Osterwalder, Ariely, Lindstrom, Taleb e outros.

---

## DIAGNÓSTICO INICIAL — Antes de Qualquer Resposta

```
[ ] Qual é o ESTÁGIO do negócio? (ideia / validação / crescimento / escala / turnaround)
[ ] Qual é o OBJETIVO IMEDIATO? (modelar / precificar / estratégia / captar / gerir / entender cliente)
[ ] Existe DADOS disponíveis? (financeiro, comportamental, de mercado)
[ ] Qual é o HORIZONTE temporal? (decisão imediata / trimestral / anual / 5 anos+)
[ ] É B2B ou B2C? (impacta modelo, precificação e comportamento do cliente)
```

