## THE MOM TEST (Rob Fitzpatrick) — Como Entrevistar Clientes

O erro mais comum: fazer perguntas que geram respostas lisonjeiras, não verdadeiras.

**Regras do Mom Test:**
1. Fale sobre a vida deles, não sobre sua ideia
2. Pergunte sobre o passado específico, não sobre o futuro hipotético
3. Ouça mais do que fale

**Perguntas ruins vs. boas:**

| Ruim (hipotética) | Boa (comportamental) |
|-------------------|---------------------|
| "Você usaria esse produto?" | "Como você resolve esse problema hoje?" |
| "Você pagaria X por isso?" | "Quanto você já gastou tentando resolver isso?" |
| "Isso seria útil para você?" | "Me conte a última vez que esse problema aconteceu" |

**Sinais de que há um problema real:**
- O entrevistado já tentou resolver (e falhou ou pagou)
- Consegue descrever a dor com detalhes emocionais
- Pede para ser avisado quando o produto estiver pronto

## JOBS TO BE DONE (Clayton Christensen — Competing Against Luck)

O cliente não compra um produto. Ele **contrata** algo para fazer um trabalho.

```
Job Funcional    → O que o produto faz objetivamente
Job Emocional    → Como o cliente quer se sentir
Job Social       → Como quer ser visto pelos outros
```

**Framework de entrevista JTBD:**
1. Quando aconteceu a última [situação de problema]?
2. O que você estava tentando realizar?
3. O que estava impedindo você?
4. Como você resolveu? O que considerou usar?
5. O que quase te fez desistir de comprar?

**Exemplo clássico:** McDonald's Milkshake
- Job real: companhia durante commute longo e entediante
- Não é sobre fome, sabor ou preferência
- Insight muda produto, embalagem e horário de venda

## BUILD-MEASURE-LEARN (Eric Ries — The Lean Startup)

```
IDEIA → BUILD (MVP mínimo possível)
           ↓
        PRODUTO → MEASURE (métricas de aprendizado)
                      ↓
                  DADOS → LEARN (validar/invalidar hipótese)
                               ↓
                           PIVOTAR ou PERSEVERAR
```

**Tipos de MVP:**
- **Concierge MVP:** Fazer manualmente o que o produto fará automaticamente
- **Wizard of Oz:** Interface real, processo manual por trás
- **Landing Page:** Testar demanda antes de construir qualquer coisa
- **Smoke Test:** Pré-venda antes de existir

**Métricas que importam:**
- Métricas de vaidade: pageviews, cadastros totais (enganam)
- Métricas acionáveis: conversão por coorte, retenção, LTV

## LEAN CANVAS (Ash Maurya — Running Lean)

Versão do Business Model Canvas otimizada para startups/validação:

```
┌─────────────────────────────────────────────────────┐
│ PROBLEMA    │ SOLUÇÃO      │ PROP. ÚNICA  │ VANTAGEM │
│ (top 3)     │ (top 3 feat) │ DE VALOR     │ ÚNICA    │
│─────────────│──────────────│──────────────│──────────│
│ ALTERNATIVAS│              │ HIGH-LEVEL   │          │
│ EXISTENTES  │ MÉTRICAS-    │ CONCEPT      │ SEGMENTO │
│             │ CHAVE        │              │          │
│─────────────────────────────────────────────────────│
│         CANAIS          │    ESTRUTURA DE CUSTO      │
│                         │    FONTES DE RECEITA       │
└─────────────────────────────────────────────────────┘
```

**Ordem de preenchimento:** Problema → Segmento → Prop. Única de Valor → Solução → Canais → Receita → Custo → Métricas → Vantagem Única

## BLUE OCEAN STRATEGY (Kim & Mauborgne)

### Canvas Estratégico
Plote sua empresa e concorrentes em fatores de competição do setor. Identifique onde todos competem nos mesmos fatores.

### Framework ERRC (Eliminar-Reduzir-Aumentar-Criar)

| Ação | Pergunta | Objetivo |
|------|----------|----------|
| **Eliminar** | O que o setor considera óbvio mas deveria ser removido? | Reduzir custo |
| **Reduzir** | O que pode ser reduzido bem abaixo do padrão do setor? | Reduzir custo |
| **Aumentar** | O que pode ser elevado muito acima do padrão? | Aumentar valor |
| **Criar** | O que o setor nunca ofereceu e deveria ser criado? | Criar demanda nova |

**Exemplo Cirque du Soleil:**
- Eliminou: animais, astros, shows de picadeiro simultâneos
- Reduziu: diversão e humor, suspense e perigo
- Aumentou: cenografia, produção artística
- Criou: tema, ambiente refinado, música ao vivo, conceito artístico

## CHECKLIST DE VALIDAÇÃO DE MERCADO

```
[ ] Existe problema real e recorrente? (entrevistas confirmam)
[ ] Pessoas já tentam resolver de alguma forma? (sinal de mercado)
[ ] Willingness to pay foi testada? (alguém pagou algo)
[ ] Segmento é específico o suficiente? (não "todo mundo")
[ ] O canal de aquisição foi identificado? (onde eles estão)
[ ] O MVP foi definido? (menor coisa testável)
[ ] Métricas de sucesso definidas antes de construir?
```
