## BUSINESS MODEL CANVAS (Osterwalder & Pigneur)

```
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│  PARCEIROS   │  ATIVIDADES  │  PROPOSTA DE │ RELACIONAM.  │  SEGMENTOS   │
│   CHAVE      │   CHAVE      │    VALOR     │  COM CLIENTE │  DE CLIENTES │
│              ├──────────────┤              ├──────────────┤              │
│              │  RECURSOS    │              │    CANAIS    │              │
│              │   CHAVE      │              │              │              │
├──────────────┴──────────────┴──────────────┴──────────────┴──────────────┤
│         ESTRUTURA DE CUSTOS              │    FONTES DE RECEITA           │
└──────────────────────────────────────────────────────────────────────────┘
```

**Ordem de preenchimento:**
1. Segmentos de Clientes (para quem criamos valor?)
2. Proposta de Valor (qual problema resolvemos / necessidade atendemos?)
3. Canais (como entregamos a proposta de valor?)
4. Relacionamento com Cliente (que tipo de relação esperamos?)
5. Fontes de Receita (pelo que clientes estão dispostos a pagar?)
6. Recursos Chave (o que a proposta de valor exige?)
7. Atividades Chave (o que precisamos fazer melhor?)
8. Parceiros Chave (quem nos ajuda a otimizar?)
9. Estrutura de Custos (quais são os custos mais importantes?)

## VALUE PROPOSITION CANVAS (Osterwalder)

```
┌────────────────────────────┐   ┌────────────────────────────┐
│      MAPA DE VALOR         │   │      PERFIL DO CLIENTE      │
│                            │   │                            │
│  [Produtos & Serviços]     │ → │  [Tarefas do Cliente]      │
│  [Criadores de Ganho]      │ ← │  [Ganhos Esperados]        │
│  [Aliviadores de Dor]      │   │  [Dores Existentes]        │
└────────────────────────────┘   └────────────────────────────┘
         FIT quando os dois lados se encaixam
```

**Como usar:**
1. Preencher o lado direito com base em pesquisa real (não suposições)
2. Priorizar as 3 dores mais fortes e os 3 ganhos mais desejados
3. Mapear seus produtos/serviços como alívios de dor e criadores de ganho

## INOVAÇÃO DISRUPTIVA (Clayton Christensen)

### Sustaining vs. Disruptive Innovation

| Tipo | O que faz | Quem ameaça |
|------|-----------|------------|
| **Sustaining** | Melhora produto para clientes existentes exigentes | Competidores estabelecidos |
| **Disruptive** | Começa com clientes ignorados, sobe gradualmente | Empresas líderes do setor |

**Por que líderes falham:**
- Escutam demais seus melhores clientes (que não querem disrupção)
- Alocam recursos para margens mais altas (sustaining)
- Ignoram mercados "pequenos demais" — que depois os destroem

**Sinal de disrupção iminente:**
- Tecnologia boa o suficiente para uso menos exigente
- Custo muito menor que o incumbente
- Começa em segmentos que líderes não se importam

## PLATFORM REVOLUTION (Parker, Van Alstyne & Choudary)

### Negócios de Plataforma vs. Pipeline

| Pipeline (tradicional) | Plataforma |
|----------------------|-----------|
| Cria valor internamente | Facilita troca de valor entre usuários |
| Produtores → Produto → Consumidores | Produtores ↔ Plataforma ↔ Consumidores |
| Cresce com ativos físicos | Cresce com efeitos de rede |
| Exemplos: Toyota, Walmart | Exemplos: Airbnb, Uber, YouTube |

### Efeitos de Rede
- **Direto:** Mais usuários = mais valor para cada usuário (WhatsApp)
- **Indireto:** Mais de um lado aumenta valor do outro lado (Uber: mais motoristas = melhor para passageiros)

### Problema do Ovo e a Galinha
Estratégias para resolver:
1. Subsidiar um lado (Uber pagou motoristas no início)
2. Criar valor standalone (GitHub era útil para 1 pessoa)
3. Simular o lado ausente (Reddit criou contas fake de conteúdo)

## ZERO TO ONE (Peter Thiel) — Filosofia de Negócio

**Tese central:** Competição é para perdedores. Construa monopólios.

**Características de um monopólio durável:**
1. Tecnologia proprietária (10x melhor que o próximo)
2. Efeitos de rede (valor aumenta com cada usuário)
3. Economia de escala (custo marginal baixo)
4. Marca forte (Apple, Google)

**Sequência de construção:**
- Dominar um nicho pequeno completamente
- Expandir para mercados adjacentes
- Nunca atacar o mercado grande diretamente no início

**Pergunta de Thiel:** "O que você acredita que é verdade que quase ninguém concorda com você?" — Respostas a essa pergunta revelam onde há oportunidade de zero para um.
