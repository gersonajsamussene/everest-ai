# 03 — Precificação

---

## PRINCÍPIOS FUNDAMENTAIS (Hermann Simon — Confessions of the Pricing Man)

**O preço é a alavanca de lucro mais poderosa e mais subutilizada.**

```
Aumento de 1% no preço   → +11% no lucro operacional (média S&P 500)
Aumento de 1% no volume  → +3,3% no lucro
Redução de 1% nos custos → +2,3% no lucro
```

### Três Estratégias de Precificação

| Estratégia | Base | Quando usar |
|-----------|------|-------------|
| **Custo + margem** | Custo de produção + % desejada | Commodities, licitações |
| **Baseada em competição** | Preço do concorrente como referência | Mercados commoditizados |
| **Baseada em valor** | Willingness to pay do cliente | Diferenciação alta, B2B |

> **A precificação baseada em valor é sempre superior** — mas exige conhecer profundamente o valor gerado para o cliente.

## WILLINGNESS TO PAY (WTP) — COMO MEDIR

### Métodos práticos:

**1. Van Westendorp (Price Sensitivity Meter)**
Quatro perguntas ao cliente:
- Que preço seria tão barato que duvidaria da qualidade?
- Que preço seria barato mas aceitável?
- Que preço seria caro mas ainda consideraria pagar?
- Que preço seria caro demais e você não compraria?

**2. Gabor-Granger**
Apresentar preços aleatórios e perguntar "compraria por X?" → Curva de demanda

**3. Conjoint Analysis**
Comparar pacotes de atributos + preço para identificar valor percebido de cada feature

**4. Teste real (preferível)**
Testar preços diferentes em segmentos ou períodos. Dados reais > dados declarados.

## PSICOLOGIA DE PREÇO (Poundstone + Ariely + Caldwell)

### Efeito Âncora
O primeiro número apresentado define o quadro de referência.
- Sempre apresente o preço mais alto primeiro
- Compare com o custo de não resolver o problema
- Compare com alternativas mais caras

### Preços Charm (Efeito Esquerda-para-Direita)
- R$99 é percebido como muito diferente de R$100
- O dígito da esquerda é processado primeiro e domina a percepção
- Usar quando o preço baixo é diferencial competitivo

### Efeito Decoy (Isca)
Inserir uma terceira opção para tornar outra mais atrativa:

```
Opção A: Produto básico — R$50
Opção B: Produto premium — R$120
Opção C (decoy): Produto médio — R$110

→ C faz B parecer excelente valor
```

### O Poder do Preço Zero
- "Grátis" não é apenas R$0,01 — é uma categoria psicológica diferente
- Gera demanda desproporcional (Ariely — Predictably Irrational)
- Risco: atrai clientes errados e desvaloriza o produto

### Precificação por Ancoragem Temporal
- Anual vs. mensal: R$99/ano soa menos que R$8,25/mês
- Dividir o preço pela unidade ("menos de R$1 por dia")
- Sempre comparar com gastos cotidianos do avatar

## MONETIZING INNOVATION — PRECIFICAR ANTES DE CONSTRUIR

**Framework de 4 perguntas antes de desenvolver qualquer produto:**

1. **Quem vai pagar?** (segmento exato, não "todo mundo")
2. **Quanto vai pagar?** (WTP por segmento)
3. **Por quê vai pagar?** (qual job to be done resolve)
4. **Como vai pagar?** (modelo de receita: único, recorrente, por uso)

**Armadilha:** Construir primeiro e precificar depois. O produto fica otimizado para features, não para valor.

## ELASTICIDADE DE PREÇO

```
Elasticidade = % variação na demanda ÷ % variação no preço

Elástica (>1): Pequena mudança de preço → grande mudança na demanda
              Ex: commodities, produtos com substitutos diretos

Inelástica (<1): Mudança de preço → pequena mudança na demanda
                Ex: produtos únicos, remédios, vício, alto switching cost
```

**Para precificar alto você precisa de inelasticidade. Para criar inelasticidade você precisa de:**
- Diferenciação real ou percebida
- Alto custo de troca (switching cost)
- Marca forte
- Lock-in de dados ou integrações

## ESTRATÉGIAS DE PRECIFICAÇÃO POR CONTEXTO

| Contexto | Estratégia | Exemplo |
|----------|-----------|---------|
| Lançamento (penetração) | Preço baixo para ganhar share | Spotify, Netflix no início |
| Produto único / inovador | Skimming — preço alto, reduz ao longo do tempo | iPhone no lançamento |
| B2B alto ticket | Value-based com ROI calculado | Software corporativo |
| Múltiplos segmentos | Versioning (Good/Better/Best) | Adobe, Microsoft 365 |
| Mercado de duas faces | Subsidiar um lado | Cartão de crédito, Google |
| Recorrência (SaaS) | Freemium + tiers de uso | Dropbox, Slack |

## ERROS MAIS COMUNS DE PRECIFICAÇÃO

1. Precificar pelo custo + margem fixa sem considerar valor percebido
2. Baixar preço como primeira resposta a objeção ("está caro")
3. Não segmentar preços por perfil de cliente
4. Oferecer desconto sem contrapartida (desvaloriza permanentemente)
5. Precificar igual ao concorrente sem diferenciação clara
6. Não testar preços (crenças sobre WTP raramente são precisas)
