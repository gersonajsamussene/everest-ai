## SISTEMA 1 E SISTEMA 2 (Kahneman — Thinking, Fast and Slow)

| | Sistema 1 | Sistema 2 |
|--|-----------|-----------|
| **Velocidade** | Rápido, automático | Lento, deliberado |
| **Esforço** | Nenhum | Alto |
| **Controle** | Involuntário | Voluntário |
| **Exemplos** | Reconhecer face, desviar de obstáculo | Cálculo, argumentação lógica |
| **Erros** | Heurísticas e vieses | Fadiga, preguiça cognitiva |

**Implicação para negócios:**
- Decisões de compra são tomadas pelo Sistema 1, justificadas pelo Sistema 2
- Interfaces, preços e mensagens devem ser processáveis pelo Sistema 1
- Complexidade ativa o Sistema 2 e pode bloquear decisão

## ARQUITETURA DE ESCOLHA (Thaler & Sunstein — Nudge)

> Não existe apresentação neutra de escolhas. Todo ambiente de escolha é um design.

**Princípios de Nudge:**
1. **Default poderoso** — o que acontece se o usuário não fizer nada deve ser o melhor resultado
2. **Friction** — adicionar atrito reduz comportamento indesejado; remover atrito aumenta o desejado
3. **Feedback** — mostrar ao usuário as consequências de suas escolhas em tempo real
4. **Simplificar** — quanto mais opções, menor a taxa de decisão (Paradox of Choice)
5. **Mapear incentivos** — alinhe os incentivos ao comportamento desejado

**Aplicação em produto/marketing:**
- Pré-selecionar opção de assinatura anual (default)
- Remover fricção do checkout (menos campos, 1-click)
- Mostrar "quantas pessoas estão olhando agora" (urgência + prova social)

## LOOP DO HÁBITO (Duhigg — The Power of Habit)

```
DEIXA (Cue)  →  ROTINA  →  RECOMPENSA
    ↑___________________________|
```

**Para criar novos hábitos:**
- Identifique o deixa existente (horário, local, estado emocional, sequência, pessoas)
- Mantenha a recompensa
- Substitua apenas a rotina

**Para quebrar hábitos:**
- Não eliminar o hábito — substituir a rotina entre o deixa e a recompensa

**Hábitos chave (Keystone Habits):**
Alguns hábitos desencadeiam uma cascata de outros hábitos positivos.
Ex: exercício regular → melhora sono → melhora alimentação → aumenta produtividade

## ATOMIC HABITS (James Clear) — Implementação

**4 Leis da Mudança de Comportamento:**

| Para criar hábito | Para quebrar hábito |
|------------------|---------------------|
| 1. Torná-lo **óbvio** | 1. Torná-lo **invisível** |
| 2. Torná-lo **atraente** | 2. Torná-lo **pouco atrativo** |
| 3. Torná-lo **fácil** | 3. Torná-lo **difícil** |
| 4. Torná-lo **satisfatório** | 4. Torná-lo **insatisfatório** |

**Identity-based habits:**
- Identidade precede comportamento
- "Quero ser uma pessoa saudável" > "Quero perder 10kg"
- Cada ação é um voto para o tipo de pessoa que você quer ser

## MOTIVAÇÃO INTRÍNSECA (Daniel Pink — Drive)

O modelo cenoura-e-chicote (recompensa/punição) funciona apenas para tarefas mecânicas.

Para trabalho cognitivo, os motivadores são:

```
AUTONOMIA   → Controle sobre o que faz, como faz, quando faz, com quem faz
MAESTRIA    → O desejo de melhorar em algo que importa
PROPÓSITO   → Fazer parte de algo maior que si mesmo
```

**Implicação para gestão:**
- Microgerenciamento destrói motivação em trabalhadores cognitivos
- Bônus financeiros para trabalho criativo frequentemente pioram o resultado
- Cultura de propósito retém talentos melhor que qualquer benefício

## MUDANÇA DE COMPORTAMENTO (Switch — Heath & Heath)

**Metáfora do elefante e o cavaleiro:**
- **Cavaleiro** = lado racional (Sistema 2 de Kahneman) — analisa, planeja
- **Elefante** = lado emocional (Sistema 1) — move, age, sente
- **Caminho** = o ambiente que facilita ou dificulta a mudança

**Para mudar comportamento, você precisa dos três:**

| Elemento | Estratégia |
|---------|-----------|
| Dirigir o cavaleiro | Apontar o destino com clareza. Não dar opções demais. |
| Motivar o elefante | Encontrar o sentimento certo, não só o argumento certo |
| Moldar o caminho | Ajustar o ambiente para tornar o comportamento certo mais fácil |

## VIESES COGNITIVOS APLICADOS A NEGÓCIOS

| Viés | Descrição | Aplicação |
|------|-----------|----------|
| **Confirmação** | Buscar informação que confirma crenças | Testar hipóteses com dados contraditórios |
| **Efeito Halo** | Avaliar tudo positivamente após uma boa impressão | Separar avaliações de pessoas e resultados |
| **IKEA Effect** | Valorizar mais o que construímos | Envolver clientes na co-criação |
| **Sunk Cost** | Continuar por causa do que já foi investido | Decidir baseado em futuro, não passado |
| **Status Quo** | Preferir o estado atual à mudança | Mudar o default para o resultado desejado |
| **Dunning-Kruger** | Incompetentes superestimam, competentes subestimam | Criar processos de feedback calibrado |
